# 概要

- 自分の作業用のもの
- ファイルの配置について：
    - Publuc状態ではあるが（次項に続く）
    - Repositoryを分ける前の一時的な物置として使うこともある
- 含まれるファイルについて：
    - まとまったスクリプトの集まりも、ツールも、コード断片も置いてよい
    - 動作確認していないものも含まれる
- Commit方針について：
    - 「適当」。Branch分け・Pull Request等も必須としない予定である。メッセージも「適当」でよい。作業の間に使う、とりあえず配置することが主の場所である。この箇条書きリストの粒度すら適当である。そのようなレベルで突っ込んでいいとするのである。
    - 1つのcommitで数千行変化することもある
